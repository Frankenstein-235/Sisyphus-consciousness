# Sisyphus-consciousness
My attempt to create language model with consciousness

WARNING: Code in file sisyphus.py will save those .pkl, .json, .py and .txt files on your computer (to the working directory) for it`s functions for each model: 
m_{name}.json (vectors of the words), 
w_{name}.json (words), 
g_{name}.json (vectors with gradients for each word),
quest_{name}.json (dictionary {question: answer} with questions and answers from text), 
y_{name}.json (number of the years that the model "lived" in revolution.py), 
artfeel_{name}.py (code of artfeel changed based on DNA),
artfeel_{name}.txt (code of artfeel changed based on DNA in .txt file), 
e_{name}.json (list of all loss function values of model),
ft_{name}.json (dictionary {function name: CPU load multiplied by some coefficient}), 
i_am_{name}.pkl (code of model class Subjective() saved in .pkl file).
